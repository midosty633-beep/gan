# مهامي — نسخة GitHub Pages محسّنة

## المزايا الجديدة
- 🪙 نظام عملات: مكافآت عند إنجاز المهام والأهداف والتحديات.
- 🎯 تحدي يومي مع مكافأة 50 عملة.
- 🏆 صفحة شارات وإنجازات تُفتح تدريجيًا.
- 📊 صفحة إحصائيات تشمل الإنجاز، السلسلة، العملات، والأيام السبعة الأخيرة.
- 🎯 وضع تركيز لمدة 25 دقيقة.
- 🔥 استمرار نظام الـStreak والمستويات والبيوت والسيارات.
- 📅 تقويم وأسماء أشهر عربية واضحة.
- 💾 حفظ البيانات محليًا في المتصفح مع دعم النسخ الاحتياطي.

## الرفع على GitHub Pages
ارفع محتويات هذا المجلد مباشرة إلى `main` في جذر المستودع `/ (root)`.
أهم ملف هو `index.html` ويجب أن يكون في جذر المستودع.
